CLEANROOM AI · AI 브리핑 36 자리 비워도 내 PC 에이전트를 스마트폰으로 승인한다: 안티그래비티 리모트 모드 해부 와이파이·모바일 데이터 연결 원리부터 Remote Control vs Remote Agents 차이, 패킷·보안 경계 실측까지

어제 [AI 브리핑.35]에서 살펴본 구글 안티그래비티(Google Antigravity)의 멀티 에이전트 협업(/swarm)처럼 작업 단위가 커질수록, 사용자는 PC 앞을 잠시 비운 사이에도 진행 상황을 확인하고 승인(Approve)하고 싶어집니다.

2026년 11월 25일 기준 최신 v2.35.2까지 업데이트된 안티그래비티는 이런 이동 중 제어를 위해 Remote Control과 Remote Agents 두 가지 원격 모드를 공식 지원합니다.

“외출할 때 스마트폰으로 내 PC 안티그래비티를 이어서 볼 수 있나요? 집이나 회사 같은 와이파이 안에서만 되는 건지, 아니면 밖에서 LTE·5G 데이터로 붙어도 패킷 요금 폭탄을 맞지 않을지 궁금합니다.”

결론부터 말씀드리면 공식 Remote Control은 PC가 역방향 터널(Reverse Tunnel)을 여는 방식이라 외부 LTE·5G에서도 포트포워딩 없이 연결되며, 화면 영상이 아닌 텍스트·로그만 주고받아 통신 패킷 부담도 원격 데스크톱보다 훨씬 가볍습니다.

1. 가장 많이 헷갈리는 3가지 원격 개념: Remote Control vs Remote Agents vs SSH

안티그래비티 문서를 처음 펼쳐보면 원격 관련 이름이 세 가지나 등장해 혼동하기 쉽습니다. 핵심 기준은 "에이전트와 파일이 실제로 어디서 돌아가는가"입니다.

Remote Control은 내 PC에 열린 작업 환경을 스마트폰이나 다른 PC 브라우저로 들여다보며 조종하는 기능이고, Remote Agents는 구글이 관리하는 격리 클라우드 환경에서 에이전트를 직접 띄우는 기능입니다. 여기에 개발자가 원격 리눅스 서버에 직접 붙을 때 쓰는 SSH Host 연결이 별도로 존재합니다.

따라서 평소 내 PC에 깔아둔 스킬과 로컬 파일 작업을 밖에서 이어 보려는 일반 사용자라면 Remote Agents가 아니라 Remote Control이 정확히 찾는 기능입니다.

2. 같은 와이파이만 될까? 외부 LTE/5G 연결 원리와 설정 방법

많은 분이 "원격 제어"라고 하면 공유기 포트포워딩이나 같은 Wi-Fi 접속을 먼저 떠올립니다. 실제로 일부 서드파티 로컬 브리지 앱은 같은 공유기 망(192.168.x.x) 안에서만 작동하기도 합니다.

하지만 안티그래비티 공식 Remote Control은 내 PC가 구글 서버 쪽으로 역방향 터널(Reverse Tunnel)을 먼저 열어두는 구조입니다.

집이나 사무실 PC가 인터넷에 연결되어 있다면, 밖에서 스마트폰 LTE·5G 모바일 데이터로 https://antigravity.google.com에 접속해 같은 구글 계정으로 로그인하는 것만으로 별도 VPN이나 공유기 설정 없이 내 PC 목록이 바로 뜹니다.

데스크톱 앱 & CLI 활성화 방법 (v2.35.2 기준)

Antigravity App(데스크톱 앱)에서 켜기: Settings(Ctrl + , / macOS Cmd + ,) → Application 메뉴로 들어가 Enable Remote Control을 On으로 켭니다. 켜자마자 아래에 Device name과 함께 전용 QR 코드 및 copy link 버튼이 나타나 스마트폰 카메라로 찍어 바로 접속할 수 있습니다. 여러 대의 PC를 구분하려면 Device name을 지정하고, 장시간 작업 중 PC가 잠들지 않게 General의 Prevent sleep도 함께 확인해 둡니다.

Antigravity CLI에서 켜기: 터미널 세션 안에서 /remote-control을 입력하거나 agy --remote-control로 실행하면 해당 세션 전용 원격 URL이 발급되며, 터미널을 닫거나 /remote-control off를 입력하면 터널이 즉시 해제됩니다.

터미널 창 없이 상시 대기(Daemon)로 쓰기: agy remote-control start를 실행하면 OS 백그라운드 서비스로 등록됩니다. 단, 공식 문서 기준 Windows에서 재부팅 시 로그인 전부터 자동 시작되게 하려면 관리자 권한 프롬프트에서 등록해야 하며, 일반 프롬프트로 등록하면 Windows 로그인 이후부터만 재개됩니다.

3. 통신 패킷 소모와 실사용에서 부딪히는 현실 제약 3가지

외부에서 LTE·5G 데이터를 켜고 antigravity.google.com을 열어두면 데이터가 크게 빠지지 않을까 걱정하기 쉽습니다.

구조를 보면 크롬 원격 데스크톱이나 팀뷰어처럼 PC 모니터 화면 전체를 초당 수십 프레임 동영상으로 쏘는 방식이 아닙니다.

대화 텍스트, JSON 형태의 도구 실행 상태, 코드 변경분(Diff), 아티팩트 문서만 동기화하므로 일반 채팅과 승인 대기 위주라면 데이터 소모가 가벼운 편입니다. (단, 모바일에서 대용량 이미지 파일을 업로드하거나 고해상도 스크린샷·리포트 아티팩트를 반복 조회하면 그만큼 데이터 사용량이 늘어납니다.)

실제 스마트폰(antigravity.google.com, App version 2.35.2) 접속 확인과 공식 문서를 대조해 보면 다음 세 가지 현실 제약은 미리 알고 써야 당황하지 않습니다.

1. 첫째, 원격 세션에서는 Remote Control 핵심 설정을 바꿀 수 없습니다.

실제 모바일 화면(Settings → Application)을 열어 확인해 보면, 원격 접속 상태에서는 Remote Control 토글 자체가 비활성화되고 "이 설정은 원격 세션이 아니라 앱을 실행 중인 컴퓨터에서만 변경할 수 있습니다(These settings can only be changed on the computer running the app, not from a remote session)"라는 보안 잠금 안내가 뜹니다. 외부에서 누군가 계정에 접근하더라도 원격 제어 스위치나 PC 앱 권한 설정을 마음대로 뜯어고치지 못하게 막는 안전장치입니다.

2. 둘째, PC가 절전 모드(Sleep)에 들��가거나 덮개가 닫히면 연결이 끊깁니다.

Remote Control은 내 PC의 하드웨어와 로컬 파일시스템 위에서 돌아갑니다. 노트북 덮개를 닫아 절전 상태로 들어가거나 인터넷이 끊기면 대시보드에서 인스턴스가 사라집니다. PC를 끄고 이동 중에도 작업을 돌리려면 클라우드 기반인 Remote Agents를 써야 하는데, 이때는 로컬 파일·로컬 MCP·설치 스킬과 /diff, /fork, /rewind, /btw, /voice 명령을 쓸 수 없는 교환 조건이 따릅니다.

3. 셋째, 사내 보안 정책에 따라 원격 제어가 막혀 있을 수 있습니다.

회사 관리자가 배포하는 admin_settings.json 정책으로 리모트 컨트롤 기능이 잠겨 있다면 개인 계정과 달리 토글이 활성화되지 않거나 Remote control is not enabled for your account 메시지가 뜹니다.

4. 외출·퇴근길에 안전하게 쓰는 클린룸 승인 관문 팁

스마트폰으로 내 PC 에이전트를 조종할 수 있다는 것은 편리한 만큼, 주머니 속 오작동이나 무심한 터치 한 번으로 로컬 파일이 바뀔 위험도 커진다는 뜻입니다. 외출 중 리모트 모드를 쓸 때는 아래 네 가지 수칙을 함께 세워 두시는 편이 안전합니다.

안티그래비티 리모트 모드 1분 사전 점검표 (복사용 체크리스트)
[1. 홈 화면에 추가] 모바일 브라우저에서 antigravity.google.com을 열어 '홈 화면에 추가'를 해두면, 에이전트가 작업을 끝내거나 승인을 기다릴 때 푸시 알림을 놓치지 않고 받을 수 있다. [2. 실행 권한은 request-review 유지] 외부에서 지켜보지 않는 사이 파일 삭제나 외부 전송이 자동 실행되지 않도록, 원격 제어용 프로젝트에서는 always-proceed 대신 승인 대기(request-review) 모드를 유지한다. [3. 절전·전원 경계 확인] 외출 전 PC 앱의 Prevent sleep 상태를 확인하고, 노트북이라면 전원 어댑터를 꽂아 둔 상태에서 덮개를 열거나 절전 설정을 조정한다. [4. 사용 후 터널 정리] 터미널 CLI에서 일회성으로 열었다면 귀가 후 /remote-control off 또는 /exit로 원격 터널을 닫아 불필요한 연결을 남기지 않는다.
마치며

안티그래비티 리모트 모드의 가치는 PC 앞에 꼼짝없이 앉아 에이전트가 긴 테스트나 보고서를 끝내기를 기다리던 시간을 돌려준다는 데 있습니다.

무거운 화면 공유 앱 대신 텍스트·승인 중심의 가벼운 웹 터널로 동작한다는 원리를 이해하고, 내 PC 자원이 필요하면 Remote Control, PC를 끄고 클라우드에서 돌리려면 Remote Agents로 역할을 나누어 활용해 보시길 권합니다.

자주 묻는 질문

Q1. 모바일에서 5G/LTE 데이터를 켜고 접속해도 정말 연결되나요?

네, 연결됩니다. 호스트 PC가 인터넷에 연결되어 Enable Remote Control이 켜져 있다면, 스마트폰에서는 Wi-Fi를 끄고 LTE·5G 데이터 상태에서 antigravity.google.com에 같은 Google 계정으로 로그인하는 것만으로 별도 포트포워딩 없이 제어할 수 있습니다.

Q2. 데스크톱 앱(Antigravity App)을 켜두는 것과 CLI(agy remote-control start)를 켜두는 것은 무엇이 다른가요?

데스크톱 앱의 Enable Remote Control은 그래픽 앱 창(에디터·사이드바)을 원격으로 연결해 주고, CLI 데몬(agy remote-control start)은 터미널 창 없이도 OS 백그라운드 서비스로 상시 대기하는 별도 인스턴스를 띄워 줍니다. 대시보드 인스턴스 목록에 두 개가 나란히 뜰 수 있으므로 Device Name과 cliRemoteControlHostname 이름을 다르게 지어 구분하는 편이 좋습니다.

Q3. 모바일에서 내 PC의 파일 접근 권한이나 보안 설정까지 바꿀 수 있나요?

데스크톱 앱의 Remote Control 핵심 설정과 CLI 설정 패널은 원격 웹 세션에서 변경할 수 없도록 잠겨 있습니다. 보안·권한 프리셋(request-review, 샌드박스 등)은 반드시 외출 전 호스트 PC에서 직접 설정해 두셔야 합니다.

1. 왜 7만 3천 명이 열광했나: Mermaid·draw.io와 무엇이 다른가

대부분의 AI 다이어그램 도구는 Mermaid 문법을 뱉어내고 화면 배치는 브라우저 렌더러의 자동 계산에 맡깁니다.

반면 Diagram Design은 에이전트가 직접 4px 격자 좌표와 1px 헤어라인 테두리, 그림자 배제(No shadows), 단일 강조색(1~2개 초점 노드 제한) 규칙에 맞춰 인라인 SVG가 담긴 단일 HTML 파일을 작성합니다.

특히 스킬의 첫 장에 적힌 핵심 철학은 실무 기획자에게도 인상적입니다.

2. 설치 전 부딪히는 3가지 실전 함정

공식 저장소(cathrynlavery/diagram-design)를 그대로 클론해 구조를 뜯어보면, 일반 사용자가 설치 직후 당황하기 쉬운 3가지 현실적 함정이 보입니다.

함정 1) 기존에 쓰던 'diagram-design' 스킬과의 이름 충돌

만약 기존에 ppt-master 같은 슬라이드 제작 스킬을 함께 쓰고 있다면, 작업 폴더의 .agents/skills/diagram-design/ 경로에 이미 14종 참조용 diagram-design이 들어 있을 수 있습니다.

이름이 완전히 같기 때문에 무턱대고 npx skills add cathrynlavery/diagram-design을 같은 루트에 덮어쓰면 기존 PPT 파이프라인의 참조 규칙이 뒤바뀔 위험이 있습니다. 설치 전 기존 skills/ 폴더 내 동명 폴더 유무를 먼저 확인해야 합니다.

함정 2) 326개 파일 구조와 Claude Desktop '200개 업로드 제한'

이번 실측에서 공식 저장소의 skills/diagram-design/ 폴더를 전수 카운트한 결과, 참조 문서 71개·예제 자산 245개·스크립트 9개·SKILL.md 1개를 합쳐 총 326개 파일로 확인되었습니다.

Claude Desktop 웹/앱의 스킬 업로드 기능은 200개 초과 ZIP을 거부하므로, 전체 폴더를 압축해 올리면 실패합니다. 대신 저장소에 포함된 빌드 스크립트(python scripts/build-claude-skill-zip.py)를 실행하면 갤러리와 다크·���니메이션 예제를 제외한 167개 파일(ZIP 내 171개 엔트리, 약 788 KB)짜리 경량 ZIP을 생성해 줍니다.

4. 한글 실무 적용 시 장점과 분명한 한계

직접 한글 다이어그램 3종을 만들고 스크립트를 통과시켜 보니, 한국어 실무 환경에서 뚜렷한 강점과 동시에 감수해야 할 제약도 분명히 드러났습니다.

점검 영역실측으로 확인한 강점주의해야 할 현실적 한계
한글 폰트·폭 계산style-guide.md에 한국어 전용 규격 (전각 1em 폭 계산, 12px 하한)이 내장됨7~8px 영문 모노 라벨 규칙을 한글에 그대로 쓰면 뭉개지므로 반드시 12px 산세리프·넉넉한 마스크로 전환 필요
레이아웃 일관성직교 화살표, 라벨 6~10px 이격, verify_geometry.py 겹침 검사로 깔끔한 결과도형 좌표를 직접 4px 격자에 맞춰야 하므로 같은 프롬프트를 다시 넣으면 배치가 조금씩 달라질 수 있음
내보내기·수정 편의export_svg.py --system-fonts로 Figma·문서에 바로 붙는 독립 SVG 추출 가능.drawio처럼 캔버스에서 마우스로 상자를 끌어서 고치기 어렵고, PNG 추출은 playwright + Chromium 사전 설치가 필수

결국 Diagram Design은 수시로 고쳐야 하는 초안 스케치 도구라기보다, 구조가 확정된 흐름이나 매트릭스를 발표자료·블로그용 '완성 인포그래픽'으로 마감할 때 가장 빛을 발합니다.

마치며

GitHub에서 7만 개가 넘는 별을 받은 이유는 화려한 애니메이션 때문이 아니라, AI가 자주 저지르는 시각적 나쁜 습관(무분별한 색상, 사선 화살표, 겹친 라벨)을 코드 수준의 제약과 검증 스크립트로 묶어냈기 때문입니다.

당장 복잡한 52종을 다 외울 필요는 없습니다. 평소 메모장이나 Mermaid로 대충 그려두었던 업무 흐름도 하나만 골라, 핵심 7~9개 노드 이하로 덜어낸 뒤 깔끔한 단일 HTML+SVG 도해로 한 번 변환해 보시길 권합니다.

자주 묻는 질문

Q1. 일반 ChatGPT나 Claude 웹 채팅창에서도 바로 쓸 수 있나요?

이 스킬은 52종 참조 문서와 검증 스크립트를 함께 불러 쓰는 구조라 일반 웹 채팅창보다는 Claude Code·Cursor·Codex 같은 에이전트 도구에서 가장 매끄럽게 작동합니다. Claude Desktop 앱을 쓰신다면 저장소 내 빌드 스크립트로 경량 ZIP(167개 파일)을 만들어 Customize → Skills에 올려 사용할 수 있습니다.

Q2. 생성된 HTML 파일이나 SVG를 오프라인 사내 PC에서도 열 수 있나요?

네, 자바스크립트 빌드 과정이 없는 순수 단일 HTML 파일이므로 브라우저로 더블클릭하면 바로 열립니다. 다만 기본 Google Fonts 요청까지 완전히 차단하려면 --system-fonts 옵션을 지정하거나 <link> 태그를 제거해야 하며, self_check.py --offline으로 차단 여부를 자동 검증할 수 있습니다.

Q3. 만든 다이어그램을 파워포인트나 피그마(Figma)로 옮기려면 어떻게 하나요?

함께 제공되는 export_svg.py로 독립 SVG 파일을 뽑아 피그마나 일러스트레이터로 가져가거나, export_png.py <입력.html> <출력.png> 2 명령으로 고해상도 PNG 이미지를 생성해 파워포인트·노션·네이버 블로그에 바로 삽입하시면 됩니다.

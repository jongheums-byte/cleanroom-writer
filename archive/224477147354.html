CLEANROOM WRITER AI 실전 08 흩어진 항공·숙소·투어 검색을 지도 한 장에 — k-skill로 나만의 여행 웹페이지 만들기 AI 실전 03의 모듈형 슬롯 구조를 여행 도메인으로 확장: 인터랙티브 지도 + 항공·숙소·액티비티·안전 4종 통합 보드 CLEANROOM AI TECH · K-SKILL TRAVEL DASHBOARD

지난 [AI 실전 03] 편에서 우리는 깃허브 오픈소스 저장소인 NomaDamas/k-skill의 생활 정보 스킬을 조립해, 필요할 때마다 부품을 갈아끼울 수 있는 모듈형 조회 대시보드를 만들어 보았습니다.

이번 [AI 실전 08] 편에서는 그 모듈형 구조를 '여행 준비'라는 구체적인 목적에 맞춰 확장해 보겠습니다.

여행을 준비할 때를 떠올려 보면 정보의 흐름이 늘 여러 곳으로 흩어집니다. 항공권은 항공 비교 사이트에서, 숙소와 입장권·투어는 여행 앱에서, 현지 안전 정보는 외교부 사이트에서 따로 찾아본 뒤, 위치 감각을 잡기 위해 다시 지도 앱을 켜야 합니다.

만약 지도 한 장 위에 내가 갈 공항·숙소·투어 핀을 띄워두고, 그 아래에 k-skill의 항공·숙소·액티비티·안전 조회 슬롯을 나란히 붙여둘 수 있다면 어떨까요?

1. 재료 확인: k-skill에 이미 준비된 여행 관련 스킬 4종

처음부터 모든 검색 기능을 새로 만들 필요는 없습니다. NomaDamas/k-skill 저장소에는 이미 여행 준비에 바로 연결할 수 있는 스킬 규격들이 정리되어 있습니다.

1. 항공권 조회 (flight-ticket-search): Google Flights 공개 검색 표면을 활용해 노선별 후보와 검색 직행 링크를 생성하는 스킬입니다. 2. 숙소·투어·액티비티 (myrealtrip-search): 마이리얼트립 공식 MCP 서버 규격을 기반으로 숙소, 투어, 티켓, 액티비티 검색과 옵션을 확인하는 스킬입니다. 3. 해외안전·여행경보 (mofa-travel-safety): 외교부 0404 국가·지역별 공식 여행경보 단계를 확인하는 스킬입니다. 4. 국내 장소·교통 보조 (kakao-map): 제주 등 국내 여행지를 선택했을 때 주변 장소와 동선을 보조로 확인하는 스킬입니다.

제약·바이오 품질관리(QC)에서 시험 성적서, 원료 이력, 설비 상태를 한 화면의 배치 기록서(Batch Record)로 묶어 보듯, 여행 정보 역시 '지도(위치)'와 '스킬 슬롯(조회)'을 한 화면에 배치하면 불필요한 탭 전환을 크게 줄일 수 있습니다.

2. 한눈에 보는 화면 설계: 지도 + 4종 슬롯 + 일정 보드

이번에 구현한 나만의 여행지도 & 4종 스킬 통합 보드는 크게 세 영역으로 나뉩니다.

상단 좌측 — 인터랙티브 여행지도 (Leaflet): 상단에서 도시(도쿄, 오사카, 제주, 파리)를 선택하면 별도 유료 API 키 없이도 지도가 해당 도시로 즉시 이동하며 공항·숙소 거점·투어 핀을 표시합니다.

상단 우측 — 핀 목록 & 원클릭 일정 담기: 지도 위 주요 지점 목록을 클릭하면 해당 위치로 지도가 확대되고, [+ 담기] 버튼을 누르면 하단의 내 여행 일정 보드에 즉시 추가됩니다.

중단 — 4종 스킬 모듈 슬롯 (SLOT #01 ~ #04): 선택한 도시에 맞춰 flight-ticket-search(항공권), myrealtrip-search(숙소 / 투어·티켓), mofa-travel-safety(또는 국내 선택 시 kakao-map) 슬롯이 자동으로 갱신됩니다.

3. 실전 설계에서 챙긴 두 가지 원칙: CORS 우회와 교차 검증

이 웹페이지를 만들면서 가장 중요하게 지킨 기준은 '보여줄 수 있는 것과 직접 확인해야 하는 것의 경계'입니다.

웹 브라우저는 보안 정책(CORS) 때문에 외부 항공사나 여행 플랫폼의 실시간 가격 서버를 직접 긁어오는 데 제약이 있습니다. 또한 항공권이나 입장권 가격은 몇 분 사이에도 변동되므로, 정적인 화면에 고정된 가격을 띄워두고 "최저가 확정"처럼 보이게 해서는 안 됩니다.

그래서 각 슬롯 하단에는 ※ 조회 전용(실시간 가격·결제는 공식 링크 확인) 안내를 명시하고, 선택한 도시와 공항 코드(ICN → NRT, KIX, CJU, CDG)가 자동으로 반영된 공식 검색 직행 버튼을 연결했습니다.

동시에 내가 고른 핀들은 브라우저의 로컬 저장소(localStorage)에 자동 저장되며, 마지막에는 [일정 Markdown 복사] 버튼 한 번으로 노션이나 메모장에 바로 붙여넣을 수 있습니다.

4. 나만의 '실행형 지도'가 주는 차이

포털에서 매번 검색어를 새로 입력하는 방식은 정보를 찾을 때마다 처음부터 다시 시작해야 하는 구조입니다.

반면, 자주 가는 여행지나 다가오는 휴가 계획에 맞춰 지도와 k-skill 조회 슬롯을 내 웹페이지로 묶어두면, 탐색의 기준점이 내 화면 안에 남게 됩니다.

거창한 여행 플랫폼을 만들 필요는 없습니다. 내가 꼭 확인하는 네 가지 요소(항공, 숙소, 투어, 안전)만 한 화면에 모아두는 것만으로도, 준비 과정의 피로도는 눈에 띄게 줄어듭니다.

AI 실전 08 · TAKEAWAY 흩어진 정보를 매번 다시 검색하는 대신, 지도(위치)와 오픈소스 스킬(조회 슬롯)을 나만의 단일 화면에 조립하면 탐색의 기준점이 내 손에 남습니다. 실시간 변동 데이터는 공식 링크로 교차 검증하고, 내 일정은 가볍게 로컬 보드에 쌓아두는 구조가 가장 실용적입니다.
